#  FAST Fest 2026 – Event Fontend Website

##  Project Overview

This project is a multi-page responsive website created for **FAST Fest 2026**.

It is built using:

* HTML5
* CSS3

The website includes multiple pages connected through a navigation bar and demonstrates various CSS styling techniques such as:

* Internal CSS
* Inline CSS
* External CSS
* Flexbox
* Grid layout
* Transitions
* Hover effects
* Animations

---

##  Website Pages

The website contains the following pages:

### 1️⃣ Home Page (index.html)

* Displays student profile information
* Includes internal CSS for font styling
* Uses inline CSS for background gradient
* Contains a navigation bar and footer

### 2️⃣ Events Page (events.html)

* Displays event cards:

  * Coding Competition
  * Singing Competition
  * Gaming Tournament
* Uses Flexbox layout
* Includes hover animation on event cards
* “Register Now” button links to registration page

### 3️⃣ Register Page (register.html)

* Contains a registration form
* Includes:

  * Name field
  * Email field
  * Contact number
  * Event selection dropdown
* Uses CSS transitions and hover scaling effects

### 4️⃣ Contact Page (contact.html)

* Includes a contact form
* Fields:

  * Name
  * Email
  * Subject
  * Message
* Styled using grid layout and card design

---

##  Styling Features (style.css)

The project uses an external CSS file (`style.css`) with the following features:

* Gradient background
* Sticky navigation bar
* Flexbox layout (events section)
* Grid layout (contact section)
* Card-based UI design
* Hover effects
* Button animations
* Box shadows
* Text shadows
* Scale transitions
* Keyframe animation (pulse effect)
* Responsive layout using max-width containers
